# คุณแอมหมูกระทะ — ระบบสั่งอาหารออนไลน์

## 1) ติดตั้ง
ต้องมี Node.js 18+ แล้วเปิด Terminal ในโฟลเดอร์นี้

```bash
npm install
npm start
```

จากนั้นเปิด:
http://localhost:3000

หลังบ้าน:
http://localhost:3000/admin

รหัสเริ่มต้น: `admin123`

## 2) ระบบที่มี
- หน้าเว็บร้านอาหาร responsive
- เมนูจาก API
- ตะกร้าสินค้า
- คำนวณยอดรวม
- ฟอร์มชื่อ/เบอร์/รับที่ร้านหรือจัดส่ง/ที่อยู่/หมายเหตุ
- บันทึกออเดอร์ลง SQLite
- หลังบ้านดูออเดอร์
- เปลี่ยนสถานะออเดอร์

## 3) ก่อนนำขึ้นออนไลน์
เปลี่ยน `ADMIN_KEY` ใน Environment Variable ของเซิร์ฟเวอร์จาก `admin123` เป็นรหัสที่เดายาก

ตัวอย่าง:
ADMIN_KEY=รหัสลับของร้าน

หมายเหตุ: ระบบนี้เป็นต้นแบบใช้งานจริงระดับร้านเล็กและยังไม่มีระบบชำระเงินออนไลน์, LINE OA, ระบบจัดส่งอัตโนมัติ หรือบัญชีผู้ใช้


## 4) หน้าติดตามรายการ
ลูกค้าเข้า:
`/tracking.html`

กรอกเลขออเดอร์ + เบอร์โทรศัพท์ที่ใช้สั่ง เพื่อดู:
- สถานะออเดอร์
- รายการอาหาร
- ยอดรวม
- ขั้นตอนการเตรียม/จัดส่ง
